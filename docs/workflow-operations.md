# 自动化流程上线与运行维护

状态：2026-09-09 已完成本地实施与隔离环境验收，尚未部署。本文不授权生产操作。

- 备份应用 PostgreSQL 数据库，并在隔离数据库验证备份可恢复。数据库备份保留媒体引用和运行记录，不能代替 OSS 对象备份或版本保护。
- 在隔离数据库验证当前版本的 `repository.DB()` 自动迁移。新增 Workflow 定义、媒体引用、运行、步骤、输出及尝试记录；图片任务增加领取令牌和租约字段，视频任务写回同时校验租约是否仍有效。运行尝试增加重试请求标识和排队／执行时间字段。
- 确认所有实例使用同一版本，避免旧图片 Worker 忽略新增租约字段，或旧清理程序忽略 Workflow 媒体引用。
- 完成 Go、Bun、TypeScript、生产构建及浏览器验收。模拟供应商验证不代表真实供应商已通过；收费生成应另行授权后验收。

## 开关与容量

| 配置 | 默认值 | 含义 |
| --- | --- | --- |
| `WORKFLOW_ENABLED` | `true` | 控制新运行及后续任务提交；关闭不取消已发送给供应商的任务 |
| `WORKFLOW_GLOBAL_CONCURRENCY` | `4` | 同一数据库内所有流程的活动生成容量 |
| `WORKFLOW_RUN_CONCURRENCY` | `2` | 单次运行的活动生成容量 |

这些配置由服务进程启动时读取。修改配置、重启及部署均是单独的上线操作。首次发布建议先关闭新流程提交，检查迁移、列表、保存和权限，再在受控范围启用。

容量限制与现有图片／视频 Worker 的处理能力共同生效。不要通过删除正在执行的尝试记录释放容量；记录还承担幂等、上游任务恢复和媒体引用保护。

## 异常处理

- **供应商明确失败**：在运行详情中查看失败槽位。重试只针对该槽位，成功结果及不依赖它的分支继续保留。
- **提交结果待确认**：保留原请求和任务记录，核对对应供应商任务；不得直接新建尝试或重新提交来消除提示。
- **查询中断或页面关闭**：页面停止观察不等于供应商任务取消。后台应继续收尾；重新打开查看同一运行记录。
- **停止流程**：停止后续执行，已提交工作继续收尾。未收尾运行不能删除。
- **媒体无法访问**：结合 `mediaId`、运行 ID 和媒体生命周期审计检查权限、引用和对象状态；不要直接删除引用表或修改结果地址。

排查时关联运行 ID、节点 ID、槽位 ID、尝试编号和生成任务 ID。日志记录任务提交、恢复和终态，日志和工单不应包含 API Key、签名 URL 或用户原始媒体内容。

新尝试的排队时长为 `startedAt - queuedAt`，执行时长为 `finishedAt - startedAt`。尚未开始的尝试没有 `startedAt`；旧记录可能缺少新增时间字段，不应把缺失值计算为零。

启动和重试请求都有独立 `requestId`。同一次用户操作发生网络重发时必须复用原值；新的重试操作使用新值。系统保留旧尝试的重试标识，迟到的旧请求不应产生额外任务。普通图片／视频接口不得使用 `workflow-` 前缀，它保留给流程调度器。

## 数据保留与回退

运行历史保留至用户主动删除。删除流程定义不删除历史运行；删除已结束运行解除其媒体引用，最后一个引用解除后由现有保留与清理机制处理，不能立即删除 OSS 对象。

功能出现问题时优先关闭新提交并保留已提交任务的收尾能力。不能直接回退到不识别 Workflow 引用或图片租约的旧版本，否则可能出现引用媒体被清理或多个 Worker 重复处理任务。需要回退时先核对所有未完成任务和媒体保护方式，采用包含这些保护的修复版本；不要通过删表或删除新增字段实现应用回退。

数据库恢复会回退任务记录，却不会回退供应商已接受的任务和 OSS 已写入的对象。恢复后启用 Worker 前应核对恢复时间点之后的任务，避免重新提交造成重复费用。

## 验证方式与当前边界

后端测试需要专用 PostgreSQL 测试库。通过 `TEST_DATABASE_DSN` 指向隔离数据库后执行 `go test ./... -count=1`；禁止将测试连接串指向生产数据库。并发验收包含领取容量、过期租约拒写、跨流程请求去重、停止收尾和重复 Retry 请求。

前端在 `web` 目录执行 Bun 相关行为测试、`bun run typecheck` 和 `bun run build`。浏览器使用独立测试账号及媒体检查流程列表、保存重开、节点拖动和连线、图片加载、视频播放、运行历史和失败重试。

本地模拟供应商仅证明应用的编排、状态和交互闭环。正式上线仍需单独授权，验证实际供应商模型契约、真实 OSS 媒体访问及收费结果；不能把本地模拟成功作为真实生成已验收的依据。
