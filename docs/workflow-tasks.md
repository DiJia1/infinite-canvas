## 执行边界

- 子代理使用 `gpt-5.6-sol`、`high`，按文件所有权分工；共享契约先确定，后续修改需同步。
- 每个 task 由主协调者核对验证、整合并串行提交，避免并行操作 Git index；子代理不自行提交其他任务文件。
- 使用现有 Go/GORM/PostgreSQL、Next.js/React/Ant Design 和 Bun；不套用门户项目技术栈。
- 自动迁移只在隔离测试数据库验证，生产迁移、备份及收费验收属于后续上线操作。
- 真实供应商生成未获授权时使用现有供应商模拟测试，明确保留真实收费验收事项。
